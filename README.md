# Órdago · UGT Sanir Programados

Adaptación de TecniMus, creado por Txuwa, con identidad propia para UGT Sanir Programados.

## Publicación

Sube TODOS los archivos de esta carpeta a tu repositorio de GitHub Pages o arrastra la carpeta descomprimida a Netlify. `index.html` debe quedar en la raíz del sitio; no subas el ZIP cerrado. Funciona también en una subcarpeta de GitHub Pages.

No requiere compilación, cuenta, servidor de juego ni claves API. Es un juego individual con un compañero y dos rivales controlados por IA; no incluye multijugador online.

## Esta edición

- Cabecera con los logos UGT y Comité de empresa Sanir Programado.
- Nombre, emblema de cartas, iconos y acceso directo propios: Órdago UGT.
- Estética de club: crema, rojo UGT y tapete verde. Adaptación móvil y escritorio.
- Reglas, cartas, IA, señas, sonidos y consejos del proyecto original.
- Preferencias propias para sonido y consejos.
- Recursos y tipografías locales. Sin dependencias externas.
- Instalación como aplicación web cuando el navegador lo permita. El botón «Instalar juego» aparece si el navegador ofrece instalación; en iPhone se utiliza Compartir → Añadir a pantalla de inicio.
- Juego sin conexión tras la primera carga completa en HTTPS y la activación de su caché.

Los cambios afectan a la identidad y presentación. La lógica de juego es la del ZIP original. Conserva la autoría de Txuwa. Los logos se han recuperado de la calculadora facilitada anteriormente.

## Actualizaciones

Para otra versión incrementa `CACHE_NAME` en `sw.js`. Si se sustituye una instalación antigua, puede ser necesario cerrar y abrir el juego y volver a añadir el acceso directo para renovar el icono.

## Comprobaciones de esta entrega

Sintaxis JavaScript, recursos locales y cinco manos simuladas con IA, apuestas y puntuación; botones de sonido y consejos. Se ha comprobado que el código del juego coincide con el original salvo las claves locales de preferencias. La revisión visual en navegador y la instalación en un móvil real quedan pendientes.
